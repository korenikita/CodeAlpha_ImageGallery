Task 1:# Image Gallery

A responsive image gallery built using HTML, CSS, and JavaScript.

## Features
- Responsive design
- Image preview
- Smooth animations

## Technologies
- HTML
- CSS
- JavaScript

## Project Description

Image Gallery is a responsive web-based project built with HTML, CSS, and JavaScript** that showcases images in an interactive and visually appealing gallery. It features next/previous navigation**, a lightbox view for enlarged image previews, hover effects, and smooth transitions to enhance the user experience. The gallery is fully responsive, ensuring seamless viewing across desktops, tablets, and mobile devices. Additionally, it includes image filtering/categories for easy image organization and browsing.
